# Course scope and evidence

FleetPulse is a software-only AI2002 project using simulated NASA C-MAPSS FD001 histories. [The user guide](product.md) describes the workflow, and [the live demo runbook](p25_live_demo_runbook.md) gives a repeatable presentation path.

The [final report](report/p25_final_report.md) records the data split, past-only feature rules, model evaluation and scheduling assumptions. [The held-out test results](p13_s3_final_test_results.md) report errors on 100 simulated engines. [The delivery map](p26_t1_delivery_manifest.md) links the current report, slides and package evidence.

The team should check these deliverables against the official course statement and verify the exact submission archive and hosted revision separately.

Human review is still needed for originality, scientific interpretation, justified assumptions, diagrams, report and slides, all member understanding, and the live demonstration. Automated inventory cannot certify those claims.
